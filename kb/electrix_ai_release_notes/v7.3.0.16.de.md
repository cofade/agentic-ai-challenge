Release v7.3.0.16 behebt einen Fehler, bei dem der Export der Stückliste unter bestimmten Bedingungen Spaltenformatierungen verlor.
Der BOM-Export berücksichtigt nun benutzerdefinierte Sortierreihenfolgen aus dem Projekt-Explorer.
Die Installationsroutine zeigt eine deutlichere Meldung, wenn weder .NET Runtime 6.0 noch eine neuere Version verfügbar ist.
