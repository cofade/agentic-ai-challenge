**Verbesserungen WSCAD ELECTRIX AI Hotfix 3**

Der WSCAD ELECTRIX AI Hotfix 3 enthält wichtige Korrekturen.

Hinweis: Die hier beschriebenen Aktualisierungen sind abhängig von Disziplin und Ausbaustufe!

#### Allgemeines

- Das Ändern der Seitennummer eines einzelnen Dokuments funktioniert korrekt.
- Ändert man die Seitennummern einiger Dokumente, wird anschließend im Projekt-Explorer der Dateiinhalt korrekt an den Dokumenten angezeigt.
- Selbstdefinierte Tastaturbefehle können korrekt ausgeführt werden.
- Im Symbol-Editor werden markierte grafische Elemente korrekt farblich hervorgehoben.
- Zieht man im Symbol-Editor mit der Maus einen Rahmen über mehrere CE-Elemente, werden diese korrekt markiert.
- Im Hauptmenü **Auswertung** lässt sich die Etikettenerstellung für Klemmen wieder ausführen.
- In der Artikelverwaltung kann der Inhalt des Feldes **Bauteilname** über das Papierkorb-Symbol korrekt gelöscht werden.
- Im Nachbearbeitungspanel einer Übersetzung kann der gleiche Text mehrfach eingetragen werden.
- Im Messstellen-Manager kann zusätzlich zu einer Excel-Datei eine SQLite-Datenbank importiert werden. Der Import einer Access-Datenbank steht nicht mehr zur Verfügung.

#### Projekte im Netzwerk

- Ein Netzwerk-Projekt kann nicht aus dem Projekt-Explorer entfernt werden, solange es von einem anderen Anwender geöffnet ist.
- Das Importieren von Projekten als Netzwerk-Projekte funktioniert korrekt.
- Beim Erstellen einer neuen Seite eines Netzwerk-Projekts wird keine bereits vorhandene Seitennummer mehr vorgeschlagen.
- Die Sicherung eines Netzwerk-Projekts funktioniert korrekt, wenn in den WSCAD Einstellungen unter **Verzeichnisse** für die temporären Dateien ein lokales Verzeichnis eingestellt ist.
- Bei einem Netzwerk-Projekt funktioniert die Änderungsverwaltung korrekt. Auch Name und Kommentar des Änderungsstandes werden wieder richtig angezeigt.
- Beim Arbeiten mit der Änderungsverwaltung bleibt der Inhalt der Seiten weiterhin sichtbar.
- Ist bei einem Netzwerk-Projekt die Änderungsverwaltung im strengen Modus aktiviert, können die einzelnen Seiten über den Kontextmenübefehl **Änderungsfreigabe** bearbeitet werden.
- Ist bei einem Netzwerk-Projekt die Änderungsverwaltung aktiviert, werden die Daten des Änderungsstands korrekt im Rahmen der geänderten Dokumente angezeigt.

#### Datenbanken

- In einer neu erstellten SQL-Artikeldatenbank können mehrere Hersteller korrekt angelegt und mit den Artikeln verknüpft werden.
- Bei der Datenübernahme von WSCAD Vorgängerversionen werden die Adressen-Datenbanken korrekt vom Access- in das SQLite-Format konvertiert.
- Im Wizard **Lexikon-Datenimport** werden die Tabelleninhalte der Access-Datei korrekt angezeigt, auch wenn zwischen verschiedenen Access-Datenbanken gewechselt wird.

#### Schnittstellen

- Beim benutzerdefinierten Phoenix Contact PROJECT complete marking Export sowie MARKING system Export werden alle Import-Schemas korrekt aufgelistet.
- Der Import einer Siemens TIA AML-Datei mit unvollständigen Datensätzen wird ohne Fehler abgeschlossen.
