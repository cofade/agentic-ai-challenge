Release v7.3.0.24 tightens installation prerequisite checks: the installer now verifies that .NET Runtime 6.0 or newer is present before proceeding.
A clearer error dialog is shown when the host operating system predates Windows 10.
The License Manager UI has been reorganised so that the offline activation entry point is reachable from the main toolbar.
