Release v7.3.2.10 adds compatibility with .NET Runtime 8.0 alongside the existing .NET Runtime 6.0 baseline.
A startup crash on Windows 11 24H2 caused by a deprecated WPF API has been resolved.
The project explorer no longer freezes when a workspace contains more than 200 sheets.
