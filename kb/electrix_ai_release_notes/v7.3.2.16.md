Release v7.3.2.16 resolves a license activation regression where the License Manager dialog appeared blank after a previously expired license was replaced.
Offline license activation now retries automatically when the seat-binding response exceeds the configured connection timeout.
The BOM export filter pane no longer loses its column ordering when a project is reopened.
